# 原生檔案 round-trip 保留節點 ID

QuickMind v1 在文件或節點建立時產生 UUID v4 字串；新建文件當下就取得文件 ID 與根節點 ID，節點暫存建立時就取得節點 ID，即使取消新增也不重用；清除本機文件後建立的新文件也一定取得全新文件與根節點 ID。節點 ID 必須在文件內唯一，文件 ID 也必須符合相同格式。有效 `.quickmind` 匯入取代工作副本時，完全採用匯入檔案內的文件 ID 與節點 ID，不沿用原工作副本身份，因此匯入同一檔案的結果具有相同身份；只有新的節點或新建文件產生新 ID。這讓身份不依賴可重複的標題或易變的階層路徑，為未來關聯、引用與資料遷移保留穩定基礎；代價是匯入驗證必須檢查 ID 的存在、格式與唯一性。
