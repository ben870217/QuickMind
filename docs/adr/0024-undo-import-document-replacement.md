# 有效匯入以完整文件取代操作處理

QuickMind v1 對任何有效 `.quickmind` 匯入採一致語義：若內容與目前工作副本完全相同則是 no-op，否則不論文件 ID 是否相同，都以一筆完整文件取代操作處理；原生檔案不包含來源 Undo／Redo 歷史，匯入只在目前工作區新增一筆取代歷史。歷史保存取代前後的完整工作狀態，包括文件 ID、內容、metadata 與未匯出狀態。Undo 還原匯入前整份工作狀態，Redo 恢復匯入文件的完整狀態，且兩者都更新 UI 狀態提示但不新增歷史，完成後立即保存恢復狀態而不改寫其 `updatedAt` 或匯出狀態。匯入成功後採用來源 metadata 與內容，立即解除文件切換確認與一般編輯限制，使用者可直接繼續操作；每個後續變更仍須通過 v1 文件規模上限檢查，超限就拒絕。匯入結果視為已匯出且沒有未匯出變更，避免依文件身份分裂操作與歷史規則。
