# v1 聚焦本機單一文件核心流程

QuickMind v1 服務需要在桌面瀏覽器分頁中獨自、私密且離線整理想法的個人桌面使用者，核心整理任務是將未成形想法快速拆解成可回看的階層結構，並採用單一本機心智圖；節點只提供單行純文字標題，視覺樣式以全域主題為限。第一階段以 50 個節點以下作為正常使用與驗收情境，不以搜尋功能為前提。v1 先交付建立、編輯、儲存、重新開啟、新增子節點、新增同層節點、重新命名、刪除子樹、拖曳移動、展開收合、Undo/Redo 與原生格式匯入匯出；刪除非根節點時連同整棵子樹移除，並由單次 Undo 完整還原，根節點不可刪除。搜尋條件保留至後續 stage，再依單一文件、標題子字串比對與結果導覽等條件實作。PWA 安裝能力列入後續 stage，不是核心 v1 驗收前提。Markdown 備註、圖片附件、個別節點樣式、XMind/OPML 相容、PDF、跨頁籤同步、時光機、Minimap、Safe Mode、團隊協作與雲端同步暫不列入核心 v1，以降低同時驗證檔案相容性、儲存可靠性與複雜工作區行為的範圍。
