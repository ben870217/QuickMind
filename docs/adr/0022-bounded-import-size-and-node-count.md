# 以檔案大小與節點數限制 v1 文件生命週期

QuickMind v1 對工作區、`.quickmind` 匯入與原生檔案匯出統一設定 10 MB 原生 JSON UTF-8 byte size 上限與 10,000 個節點上限，節點計數包含收合分支中的全部節點。這是資料與檔案生命週期的拒絕邊界，不代表 v1 必須以 10,000 個節點提供良好渲染效能；第一階段的正常使用與驗收情境仍是 50 個節點以下。匯入在解析前檢查檔案大小，工作區拒絕會超量的建立或編輯，匯出只允許成功序列化且不超量的文件；匯入成功後仍可正常編輯，但每個會改變文件的操作都必須檢查結果是否超限。任何超限操作都完全不套用、不建立 Undo 歷史、不更新 `updatedAt`、不觸發自動保存，並只在拒絕時說明目前使用量與上限，平時不增加容量狀態 UI。不自動截斷、刪除或部分載入。這優先保證 v1 產出的 `.quickmind` 可由同版重新匯入；大規模渲染、搜尋與效能最佳化留待後續 stage，後續版本需另行設計超大心智圖的內容救援出口。
