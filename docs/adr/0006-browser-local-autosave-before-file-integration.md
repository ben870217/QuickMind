# v1 以瀏覽器本機自動保存為主要持久化方式

QuickMind v1 將新建或編輯中的文件自動保存為瀏覽器本機工作副本；一般變更停止 500ms 後保存，新建完成、匯入成功、刪除或拖曳完成，以及頁面隱藏或關閉前立即嘗試保存。新文件在建立當下即持久化，重新啟動時若存在工作副本就直接恢復，即使使用者尚未匯出原生檔案。只有不存在工作副本時才建立「未命名心智圖」。原生檔案只在使用者明確執行匯出時透過瀏覽器標準下載產生，檔名由根節點標題清理後產生：非法檔名字元替換為 `_`，去除開頭與結尾的空白及句點，最多保留 100 個使用者可見字元；若清理結果命中 Windows 保留名稱，前綴 `_`；副檔名判斷不分大小寫，若標題已以 `.quickmind` 結尾則不重複追加，實際輸出統一使用小寫 `.quickmind`；清理後若為空則使用 `未命名心智圖.quickmind`。下載成功後才清除未匯出變更狀態；匯出失敗時保留記憶體內容、未匯出狀態與本機保存狀態，顯示可重試錯誤。v1 暫不採用 File System Access API 的靜默覆寫、檔案 handle 保存或 OS 雙擊開啟，以降低瀏覽器權限、相容性與檔案生命週期的複雜度；代價是編輯後不會自動更新磁碟上的既有檔案。
